Run Codex non-interactively
Usage: codex exec [OPTIONS] [PROMPT]
Arguments:
  [PROMPT] instructions are read from stdin when `-` is used
Options:
  -m, --model <MODEL>
  -s, --sandbox <SANDBOX_MODE>
  -C, --cd <DIR>
      --ephemeral
      --ignore-user-config
      --output-schema <FILE>
      --json
  -o, --output-last-message <FILE>
